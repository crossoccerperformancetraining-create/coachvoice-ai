# CoachVoice AI v4.3 — Mentor IA em Voz e Vídeo

Nova **Videochamada** dentro do Mentor IA:
- sua câmera em uma janela pequena;
- avatar visual do Mentor no centro;
- resposta em voz e texto;
- legenda;
- animação enquanto o Mentor fala;
- botão para ligar/desligar a câmera.

O avatar é visual e animado. Não é vídeo humano real nem faz leitura de emoções.

Publicação:
1. Extraia o ZIP.
2. Envie todos os itens de dentro da pasta ao GitHub.
3. Confirme somente uma pasta `api/`.
4. Commit: `Adicionar videochamada visual do Mentor IA v4.3`
5. Teste: `https://coachvoice-ai.vercel.app/?v=43`
